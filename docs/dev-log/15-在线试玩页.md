# 15 · 在线试玩页（GitHub Pages）

> 目标：路过的人不用申请 Token、不用在本地起服务，打开链接就能输入蛋白质和预算看结果。
> 线上地址：<https://fanzhangnan.github.io/mcd-protein-calculator/>
> 仓库：<https://github.com/FanZhangnan/mcd-protein-calculator>

## 一、做法

浏览器里不跑 Python，也不请求任何后端。单餐的合法组合数量有限，可以在导出时一次算完，前端只做筛选和排序：

```
实时 MCP → scripts/export_demo_snapshot.py → docs/demo/snapshot.json
                                                  │
浏览器 docs/index.html → web/solver.js（纯函数）→ 结果卡 / 散点图
```

- **导出**：`scripts/export_demo_snapshot.py` 用 `LiveProvider` 刷新菜单（`source=live` 才继续），按 `planner.build_meal_options` 的结构规则（主食 1–3 个、白名单饮品 0–1、配菜 0–1）枚举组合，写入 `docs/demo/snapshot.json`。
- **求解**：`web/solver.js` 复刻 `src/planner.py` 的硬约束、排序、容差、省钱选项与放宽方案；不枚举，只过滤快照里的组合。
- **页面**：`docs/index.html` + `docs/demo/`。`app.js`、`style.css`、`solver.js` 是 `web/` 同名文件的**逐字节副本**（`scripts/sync_demo_assets.py` 同步，`tests/test_demo_assets.py` 校验哈希），渲染逻辑只有一份。
- **接口适配**：`docs/demo/snapshot-shim.js` 拦截 `fetch("/api/*")`，用快照回答 `bootstrap` / `landscape` / `meal` 等请求，页面因此可以直接复用 `web/app.js`，且不产生任何真实网络请求。

## 三、一致性测试

`tests/test_demo_parity.py` 用同一份快照启动离线后端（把导出时的原始缓存写入临时 `MAI_MAI_DATA`，不联网），对 672 个输入逐个比较 `/api/meal` 与 `web/solver.js`：

| 维度 | 取值 |
| --- | --- |
| 餐次 | 早 / 午 / 晚 |
| 蛋白质 | 20, 25, 30, 35, 40, 44, 50, 55 |
| 预算 | 15, 20, 25, 30, 35, 45, 60 |
| 容差 | 0, 3 |
| 脂肪上限 | 无, 30 |

比较项：主方案的商品与数量、总价、总蛋白质、状态（`met` / `near` / `under`）、省钱选项（价格与商品）、放宽价格方案的价格、预算内上限的蛋白质。

**结果：672 / 672 全部一致**（约 3.5 分钟）。默认 `unittest discover` 会跳过这组慢测试，显式运行：

```bash
RUN_DEMO_PARITY=1 NO_PROXY=127.0.0.1,localhost python3 tests/test_demo_parity.py
```

## 四、页面验收

`tests/demo_ui.mjs` 用 Chrome 无头模式跑 12 项断言，全部通过：

| 场景 | 断言 |
| --- | --- |
| 午餐 44 g / 45 元 | 达标，双层吉士汉堡 ×2，54 g，45.00 元，省钱选项 42 g / 39.00 元 |
| 午餐 35 g / 25 元 | 预算内最多 28 g / 25.00 元，出现「加预算到 39.00 元」卡片 |
| 同上点按钮 | 预算改为 39 元并重算 → 42 g / 39.00 元达标 |
| 早餐 25 g / 20 元 | 达标（27 g / 18.50 元） |
| 网络 | 只有 `/`、`demo/*`、`favicon.ico`，没有 `/api/` 或跨主机请求 |
| 报价 | 没有「为这一餐报价」按钮，只有说明与 README 安装链接 |
| 点单建议 | 只列出可去除配料名称，没有 checkbox |
| 手机 390 px | `scrollWidth = innerWidth = 390`，无横向滚动 |

## 五、已知限制

- 快照是**某一时点**的菜单与价格，不是实时价；页面徽标、结果卡和页脚都写明了这一点，报价按钮替换为说明文字。
- 快照日期为 2026-10-22（导出时下一个可预订日），与实际到店日无关，只用于展示同一门店的完整菜单。
- 只做珠海屏湾一路一家店；换门店需要重新导出。
- 在线版不显示券后价（第二阶段功能），因为没有登录账号，也不调用任何交易接口。
